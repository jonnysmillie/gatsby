## How to Contribute

For information related to contributing to Gatsby, please check out the [How to Contribute](https://www.gatsbyjs.org/contributing/how-to-contribute/) section of the documentation at the Gatsby site.

### Contribution Guidelines

- **Code of Conduct:** Please adhere to our [Code of Conduct](https://www.gatsbyjs.org/contributing/code-of-conduct/) to ensure a welcoming environment for all contributors.

- **Reporting Issues:** If you encounter a bug or have a feature request, please open an issue in our [GitHub repository](https://github.com/gatsbyjs/gatsby/issues). Be sure to include as much detail as possible to help us understand the problem.

- **Pull Requests:** When submitting a pull request, ensure that your code adheres to our coding standards and passes all tests. Include a clear description of the changes and reference any related issues.

- **Documentation:** We welcome contributions to our documentation. If you notice any inaccuracies or areas for improvement, feel free to submit a pull request with your suggestions.

- **Stay Updated:** Follow our [Changelog](https://github.com/gatsbyjs/gatsby/blob/master/packages/gatsby/CHANGELOG.md) for updates on new features, bug fixes, and breaking changes.

Thank you for considering contributing to Gatsby! Your efforts help make Gatsby better for everyone.
